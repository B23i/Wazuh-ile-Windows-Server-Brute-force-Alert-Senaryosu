# Wazuh-ile-Windows-Server-Brute-force-Alert-Senaryosu
Bu raporda, tamamen lab ortamında hazırlanan bir SIEM senaryosu anlatılmaktadır. Amaç; Windows Server üzerinde gerçekleşen başarısız RDP oturum açma denemelerinin Wazuh SIEM tarafından toplanması, özel bir alert kuralı ile ilişkilendirilmesi ve brute-force aktivitesi olarak görüntülenmesidir.
